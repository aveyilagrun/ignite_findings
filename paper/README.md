# Article draft (Energy Research & Social Science)

## Open in Overleaf

1. Zip this `paper/` folder (it must contain `main.tex` and `figures/`).
2. In Overleaf, choose **New Project → Upload Project** and select the zip.
3. Set the compiler to pdfLaTeX (the default). The `elsarticle` class is built into Overleaf.

Blue `[NOTE: ...]` text marks notes of things that are still to confirm, add or decide.

# Ignite Research: gender representation in energy publications

This project measures how women are represented among first authors of energy-research articles, and whether research impact differs by gender. It covers six Elsevier journals and eight countries (UK, USA, Canada, France, Germany, Switzerland, South Africa, Singapore) from 2010 to 2025.

**Start here:**
- [`HANDOVER.md`](HANDOVER.md) explains where the project stands, the open decisions, and known issues.
- [`FINDINGS.md`](FINDINGS.md) lists the findings that are verified on the current data.
- [`results/`](results/) holds the numbers behind the findings, generated by the scripts.
- [`paper/`](paper/) contains the Overleaf-ready article draft.

## Repository layout

```
├── HANDOVER.md                       status, decisions, next steps
├── FINDINGS.md                       verified findings
├── scripts/
│   ├── headline_stats.py             all headline numbers → results/headline_stats.md/.json
│   ├── extra_analysis.py             seniority, teams, trends by journal/country, keywords → results/extra_analysis.md
│   └── paper_figures.py              article figures → paper/figures/
├── results/                          generated outputs of the scripts (do not edit)
├── paper/                            main.tex, figures/ (see paper/README.md)
├── data/                             data dictionary (data/README.md); the data files are not in the repository
├── extract_data.ipynb                step 1: ScienceDirect text exports → extracted_data/*.csv
├── process_data.ipynb                step 2: + Crossref, Scopus h-index, PlumX metrics, Namsor gender
├── affiliation.ipynb                 side step: OpenAlex affiliations for the Singapore subset
├── analysis/
│   ├── analysis.ipynb                multi-country exploratory analysis (2025) + its figures (*.png)
│   └── 1_… 6_…, common_words.ipynb   UK-phase notebooks (2024); need files not in this repo
└── docs/
    ├── presentations/                2024 EFL slides, 2025 IGNITE slides, draft .pptx
    └── notes/                        2025 written report on gender-classification confidence
```

The data is not in the repository. Ask Azhar for `processed_data/` (or the `.7z` archives of each pipeline stage) and place it in the repository root. `archive/` (old scrapers; do not use) is also kept out.

## Pipeline

```
ScienceDirect exports ─► raw_data/ ─(extract_data.ipynb)─► extracted_data/
   ─(process_data.ipynb: Crossref, Scopus, PlumX)─► elsevier_data/
   ─(process_data.ipynb: Namsor)─► processed_data/*_genders.csv
   ─► scripts/headline_stats.py ─► results/  ─► scripts/paper_figures.py ─► paper/figures/ ─► paper/main.tex
   └► analysis/analysis.ipynb (exploration)
```

## Setup

Python 3.9 was used.

```bash
python -m venv env
env\Scripts\activate            # macOS/Linux: source env/bin/activate
pip install -r requirements.txt
# then put the processed_data/ folder in the repository root (see above)
```

You only need API keys to re-run data collection (`process_data.ipynb`):

```bash
set SCOPUS_API_KEY=...   # macOS/Linux: export SCOPUS_API_KEY=...
set NAMSOR_API_KEY=...
```

## Reproduce the results

Run from the repository root:

```bash
python scripts/headline_stats.py
python scripts/extra_analysis.py
python scripts/paper_figures.py
```

Then upload `paper/` to Overleaf (see `paper/README.md`).
